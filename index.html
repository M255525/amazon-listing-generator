AMAZON LISTING GENERATOR

商品名稱＋商品資訊，一鍵產生中英對照 Amazon 標題與5點說明

貼上或上傳你的商品資訊，依 Amazon「關於本商品」規範產出標題與 5 點式賣點說明，繁體中文與英文並列，並自動標示可能違反平台規範的內容。

1商品資訊

填寫商品名稱與商品資訊（可直接貼上，或用下方按鈕上傳文字檔帶入），也可以先點右下角快速範例試玩。

支援 .txt／.md，內容會直接取代上方商品資訊欄位
AIAI 連線設定（選填）

不填也能用——沒有金鑰時會用規則式引擎，把商品資訊直接切成 5 段組成基本版說明（不含翻譯）。想要真正雙語、貼合 Amazon 撰寫慣例的內容，請填入你自己的語言模型 API 金鑰。

API 連線設定

金鑰只存在這台電腦的瀏覽器（localStorage），不會送到本工具以外的任何地方；按下「產生」時，若有填金鑰才會把商品資訊直接傳送給你選擇的服務商 API。請勿在共用電腦上填寫金鑰。

使用警語
  • 本工具產出的標題與5點說明僅供撰寫參考，不保證完全符合 Amazon 當下最新的審核規則，上架前請自行對照 Amazon 賣家後台的正式規範逐項確認。
  • 「規則式合規檢查」只涵蓋常見違規類型（價格/URL/聯絡方式/宣傳詞/長度），不涵蓋 Amazon 全部規則，未被標示不代表一定合規。
  • 請勿在任何欄位輸入真實個資、機密資料或受著作權保護的他人內容——欄位資料只存在你自己瀏覽器的 localStorage，不會上傳到任何伺服器。
  • 填有 API 金鑰時會直接連線到你選擇的服務商，該金鑰只存在你的瀏覽器，本工具不會經手或保存金鑰，也不會向你收取任何 API 費用——實際費用依你與該服務商的方案計算。
  • AI 生成內容可能有誤，使用前請自行查證；本工具與創作者不對後續 AI 輸出結果或因此產生的上架爭議負責。
  • 僅供教學、課程及個人使用，禁止未經授權公開發布、販售或商業化使用。
